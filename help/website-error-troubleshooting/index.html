I see an error on my website

Last updated: 05-26-2026    3 min read

On this page

  • Common error messages
  • Before contacting us, try these steps
  • When to contact us immediately
  • How to report an error

Seeing an error on your website can be alarming, but most issues have simple explanations. Here's a guide to common errors and what they mean.

Common error messages

404 Not Found
The page doesn't exist or was moved
Check the URL for typos. If correct, the page may have been deleted or renamed.
500 Internal Server Error
Something went wrong on the server
Usually temporary. Wait a few minutes and refresh. If it persists, contact us.
503 Service Unavailable
Server is temporarily overloaded or under maintenance
Wait a few minutes and try again. We may be performing updates.
"Connection Not Private"
SSL certificate issue
Contact us immediately — this affects site security and trust.
Blank White Page
Code error or plugin conflict
Try refreshing. If it persists, contact us for investigation.

Before contacting us, try these steps

  1. Hard refresh: Press Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
  2. Clear your cache: Clear browser cookies and cached files
  3. Try incognito mode: Open the site in a private/incognito window
  4. Try another device: Check if the error appears on your phone or another computer
  5. Check your internet: Make sure you're connected and other sites work

When to contact us immediately

Some issues require urgent attention:

  • Your entire website is down (not just one page)
  • You see a security warning or "Not Secure" message
  • Your site has been defaced or shows content you didn't add
  • Contact forms or payment systems aren't working
  • The error has persisted for more than 30 minutes

How to report an error

When submitting a request, please include:

  • The exact error message or what you see
  • The URL where the error appears
  • A screenshot if possible
  • What you were doing when the error occurred
  • What device and browser you're using
Urgent? If your site is completely down or you suspect a security issue, select "URGENT, site down" on the request form and we'll prioritize your issue.
