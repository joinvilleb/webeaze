Can you set up a Facebook Pixel or Google Tag?

Last updated: 04-20-2026    2 min read

On this page

  • What we can install
  • What you'll need to provide
  • Is it included in my plan?

Yes. We can install tracking pixels and tags on your website, including the Facebook (Meta) Pixel, Google Tag Manager, and Google Analytics 4. These are useful if you're running paid ads or want detailed visitor tracking for retargeting.

What we can install

  • Facebook (Meta) Pixel: Tracks website visitors so you can run retargeting ads on Facebook and Instagram. Required if you're running Meta ads.
  • Google Tag Manager: A tag management container that lets you add and manage multiple tracking scripts from one dashboard without code changes each time.
  • Google Analytics 4 (GA4): Tracks visitors, traffic sources, and on-site behavior. See How do I set up Google Analytics?
  • TikTok Pixel: Used for TikTok ad campaigns and retargeting.
  • LinkedIn Insight Tag: For B2B businesses running LinkedIn ads.

What you'll need to provide

Each platform gives you a unique Pixel ID or tracking code from your ad account. Share it through the client portal and we'll install it. You'll need an active account on the platform first.

Is it included in my plan?

Yes. Installing a pixel or tracking tag is included as a standard update. Submit a request with your Pixel ID or tracking code and we'll get it added.
